# Безопасность

Об уязвимости сообщайте приватно: [создайте security advisory](https://github.com/octrow/repo-scout/security/advisories/new). Не открывайте для этого публичный issue.

Первый ответ - в течение 7 дней. Исправления выходят в следующем релизе; поддерживается только последний релиз.

repo-scout работает на вашем компьютере. Он читает GitHub через ваш вход в `gh` и хранит API-ключи в `~/.config/repo-scout/.env` (файл доступен только вам). Ключ отправляется только на тот сервис, которому он принадлежит.
