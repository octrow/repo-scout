# 0002. Продвинутый режим: внешние модели — опциональные дополнения, которые не меняют порядок выдачи

Дата: 2026-10-12 · Статус: принято

## Контекст
repo-scout ранжирует без генеративных моделей (CONTEXT.ru.md, «Без LLM»). Но пользователям нужны две вещи, которые дают только внешние модели: запросы, написанные по потребности на любом языке (Черновик LLM), и оценка, может ли результат действительно стать основой для задачи. Модель System One (Jev от TypeSafe) отвечает на типизированные вопросы «да/нет» калиброванными вероятностями, и для второй задачи подходит лучше чат-модели.

## Решение
Два режима. **Базовый** (по умолчанию) не требует ключей. **Продвинутый** включает части по ключам: `LLM_API_KEY` — Черновик LLM (любой OpenAI-совместимый эндпоинт; бесплатные варианты — OmniRoute и Ollama), `TYPESAFE_API_KEY` — **Пригодность (Fit)**. Fit — один запрос на Прогон, по одному вопросу `noul` на каждого из верхних прошедших кандидатов (20), результат — колонка. Он никогда не отбрасывает и не переупорядочивает строки, а прогоны replay/eval его не вызывают, поэтому измерения полноты остаются детерминированными. Ключи лежат в `~/.config/repo-scout/.env`, их заполняет `repo-scout config`; `OMNIROUTE_*` читаются как алиасы.

## Отклонённые варианты
- **Сортировать по Fit (или Fit × Близость) в продвинутом режиме.** Не измерено: может опустить репозитории, которые эталонные наборы отмечают `→ Study`. Вернуться, только если eval покажет, что Fit улучшает полноту в верхней части выдачи.
- **Fit через OpenAI-совместимую LLM.** Ответы свободным текстом надо разбирать, они не калиброваны; ещё один промпт на поддержку.
- **Один переключатель режима (`REPO_SCOUT_MODE=advanced`).** Избыточно: ключ уже говорит, что пользователь хочет эту часть, а части независимы.

## Когда пересмотреть
- Eval на эталонных наборах показывает, что порядок по Fit находит больше `→ Study` в первой десятке → сделать Fit ключом сортировки в продвинутом режиме.
- Стоимость или задержка Fit становятся заметны (больше k, много прогонов) → пакетировать по страницам в GUI или кэшировать Fit по (задача, репо) в Индексе.
