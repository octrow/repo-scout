# Журнал изменений

Формат по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

## [0.1.13] - 2026-11-05

### Исправлено
- Модель эмбеддингов грузится до первого поиска; офлайн без кэша выход с кодом 1 и подсказкой `repo-scout doctor --fix`, квота не тратится.
- `--must` проверяет и метаданные строк `no details`.
- `eval --top` и `eval --from-index` отклоняют отрицательные значения.
- Ответ с историей звёзд не в виде списка объектов даёт понятную ошибку, а не падение.
- Сохранённый запуск с неверными `flags` или `score` отклоняется при загрузке.

## [0.1.12] - 2026-11-01

### Исправлено
- `--lang "Jupyter Notebook"` и другие языки из нескольких слов берутся в кавычки в запросе.
- Отрицательные `--months`, `--new-days`, `--limit`, `--from-index`, `--round2-k` и `--stars-k` отклоняются; раньше `--stars-k -1` проверял все строки, кроме последней. Числовые поля GUI не опускаются ниже 0.

## [0.1.11] - 2026-11-01

### Исправлено
- Второй круг берёт темы из строк выше `--min-closeness`, в том числе пониженного; раньше порог не опускался ниже 0.64. В eval остаётся 0.64.
- `--record` в папку, где уже есть снапшоты, использует дату этой записи, поэтому `--replay` даёт ту же свежесть.
- Все запросы проверяются по лимитам GitHub до первого обращения, поэтому плохой последний запрос больше не тратит квоту на предыдущие.
- GUI: в запусках, сохранённых по-русски, строки второго круга показываются как `round two` (а не отдельным `round 2`), а фильтр вердиктов на странице Индекса находит и вердикты на русском.
- Лимит запросов GitHub при загрузке README и коммитов останавливает запуск с `GitHub: …` (exit 1) после обычных повторов. Раньше все репо пропускались по одному и оставались непроверенными с флагом `no details`, а запуск сохранялся.
- Без `gh` в PATH repo-scout подсказывает, где взять GitHub CLI, а не печатает traceback Python.

## [0.1.10] - 2026-11-01

### Исправлено
- `--exclude` и `--must` сравниваются с именем репо без логина владельца: `--exclude bot` больше не отсеивает `botpress/agent-kit`.
- `--must` проверяет репо без README по имени, описанию и темам, как обещает справка; раньше они пропускали проверку и оставались. `README.markdown`, `README.txt` и `README.org` теперь считаются README.
- Репо из Индекса подчиняются `--months` и `--lang`, как результаты поиска: более старые отсеиваются как `pushed before <дата>`, а при `--lang` репо без языка отсеивается как `no language`.
- Репо, отсеянные как dead, toy, no code или noise, удаляются из Индекса (вердикты остаются) и больше не занимают места `--from-index` в каждом запуске. `--from-index N` теперь добавляет N репо, которых ещё нет в результатах поиска.
- `--lang cpp`, `--lang golang` и другие частые алиасы GitHub больше не отсеивают всю выдачу: GitHub отдаёт `C++` и `Go`, и проверка языка теперь сначала переводит алиас.
- `--months` больше 6 и `--months 0` работают: правило `dead` допускает тот же возраст (30 × месяцев), а `0` его выключает. Раньше всё старше 6 месяцев отсеивалось, что бы ни стояло в `--months`.
- `--must` и `--exclude` видят весь README: раньше он обрезался до 6000 знаков, и нужное слово дальше по тексту отсеивало репо. Теперь предел 100 000 знаков.
- GUI сохраняет `--no-fit`: вставленная команда и повтор сохранённого запуска его больше не теряют, в форме поиска есть флажок «Без колонки «Пригодность»».

## [0.1.9] - 2026-11-01

### Безопасность
- GUI отвечает только на имена хоста `127.0.0.1` и `localhost`: страница, которая перенаправила своё DNS-имя на 127.0.0.1, больше не может им управлять.
- Запрос колонки «Пригодность» (fit) к TypeSafe не идёт по редиректам, поэтому ключ API не уйдёт на другой хост.

### Изменено
- CI и pre-commit теперь проверяют форматирование ruff, предел сложности (10) и типы через ty; длинные функции разбиты на небольшие помощники, поведение перед этим закреплено тестами.

## [0.1.8] - 2026-10-30

### Добавлено
- `docs/logic-map.md`: как запуск поиска проходит через код, шаг за шагом; синхронность с кодом проверяет тест.
- Кодекс поведения на русском (официальный перевод Contributor Covenant 2.1).

### Исправлено
- Поиск больше не падает, когда GitHub отдаёт пустой (null) коммит в истории репозитория.
- `eval --fake-stars` закрывает прочитанный файл с метками.
- Поиск больше не падает, когда GitHub не смог обновить репозиторий из Index; репозиторий остаётся в Index.
- Репозиторий, который GitHub не вернул из-за ошибки (а не потому, что он удалён), больше не удаляется из Index.
- Ответ GitHub с пустыми данными повторяется, а не обрывает поиск.
- Репозиторий без единого пуша (`pushedAt` null) больше не роняет Triage; его возраст считается от создания.
- `eval --fake-stars` переживает удалённый репозиторий, пустую запись форка и файл меток с одним классом.
- GUI: черновик, чей файл запуска удалён, открывает пустую форму с уведомлением, а не ошибку.
- LLM draft читает JSON-ответ, за которым идёт текст с фигурными скобками, а нетекстовый ответ показывает как ошибку вместо падения.
- Сохранение настроек больше не оставляет в `.env` старый дубликат ключа, который перекрывал новое значение; файл сразу создаётся с доступом только для владельца.
- `eval` называет недостающие ключи в сломанном файле набора вместо трейсбека.

### Безопасность
- Обновлены зависимости с известными уязвимостями: certifi 2026.10.19, filelock 4.2.1, fastembed 0.9.1, pillow 13.0.0.
